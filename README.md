# ระบบเทรดทองคำอัตโนมัติ (XAUUSD)

ระบบเครือข่ายที่ต่อ **AI วิเคราะห์ → ตรวจความเสี่ยง → ส่งออร์เดอร์ → แสดงผลบนแดชบอร์ด** เข้าด้วยกัน

> ### ⚠️ อ่านก่อนใช้งาน
> ระบบตั้งค่าเริ่มต้นเป็น **โหมดจำลอง (paper)** ไม่ส่งออร์เดอร์จริง
> การเทรดด้วยเงินจริงต้องเปิดสวิตช์ `XAU_ALLOW_LIVE=true` เอง
> **กรุณาทดสอบบนบัญชีเดโมอย่างน้อย 2–4 สัปดาห์ก่อนใช้เงินจริง**
> การเทรดอัตโนมัติมีความเสี่ยงสูงมาก คุณอาจเสียเงินทั้งหมดได้

## โครงสร้างไฟล์

## เริ่มใช้งานใน 5 นาที (โหมดจำลอง)

### ขั้นที่ 1 — ติดตั้ง

```bash
cd trading_webapp/backend
python3 -m venv .venv
source .venv/bin/activate        # Windows ใช้:  .venv\Scripts\activate
pip install -r requirements.txt
```

### ขั้นที่ 2 — ตั้งรหัสผ่าน

```bash
cd trading_webapp
cp .env.example .env
```

เปิดไฟล์ `.env` แล้วแก้บรรทัด `XAU_API_TOKEN=change-me` เป็นรหัสที่เดายาก
สร้างรหัสสุ่มได้ด้วย:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

### ขั้นที่ 3 — เปิดเซิร์ฟเวอร์

```bash
cd trading_webapp/backend
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

เห็นข้อความ `paper broker selected — no real orders will be sent` แปลว่าถูกต้อง (โหมดจำลอง ปลอดภัย)

### ขั้นที่ 4 — เปิดแดชบอร์ด

เปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:8000**
ใส่รหัสที่ตั้งไว้ในขั้นที่ 2 แล้วกดเชื่อมต่อ

### ขั้นที่ 5 — ลองส่งสัญญาณ

เปิดหน้าต่าง terminal อีกอัน:

```bash
cd trading_webapp/langflow_bridge
export XAU_API_TOKEN=รหัสที่คุณตั้งไว้
python3 bridge.py BUY --confidence 0.85 --entry 2400 --sl 2396 --tp 2408
```

ควรได้ผลลัพธ์ประมาณ `ACCEPTED: BUY 0.12 lots @ 2400.15 — order placed`
แล้วจะเห็นออร์เดอร์โผล่บนแดชบอร์ดทันที

## การจัดการความเสี่ยง (ส่วนที่สำคัญที่สุด)

ทุกสัญญาณต้องผ่านด่านตรวจก่อนเสมอ ไม่มีทางลัด ถ้าไม่ผ่านข้อใดข้อหนึ่ง = ไม่เปิดออร์เดอร์

| ด่านตรวจ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| ความมั่นใจขั้นต่ำ | 60% | AI ไม่มั่นใจพอ → ไม่เทรด |
| ความเสี่ยงต่อไม้ | 0.5% | คำนวณขนาดล็อตอัตโนมัติจากระยะ SL |
| จำนวนไม้พร้อมกัน | 2 | เกินนี้ไม่เปิดเพิ่ม |
| ขาดทุนสูงสุดต่อวัน | 3% | ถึงเพดาน → **หยุดเทรดและปิดทุกไม้ทันที** |
| สเปรดสูงสุด | $0.60 | สเปรดกว้างผิดปกติ → ไม่เข้า |
| ทิศทาง SL | บังคับ | BUY ต้องมี SL ต่ำกว่าราคาเข้าเสมอ |
| เวลาเทรด | ตลอดเวลา | ตั้งช่วงเวลาได้ใน `.env` |

**การคำนวณขนาดล็อต** — ระบบคิดย้อนจากความเสี่ยงที่ยอมรับได้:

> พอร์ต $10,000 · เสี่ยง 0.5% = $50 ต่อไม้
> ถ้า SL ห่าง $4 → ขาดทุนต่อ 1 ล็อต = 4 × 100 ออนซ์ = $400
> ดังนั้นเปิดได้ $50 ÷ $400 = **0.12 ล็อต**

แปลว่าถ้าโดน SL จะเสียแค่ $50 ตามที่ตั้งใจไว้ ไม่ว่า SL จะห่างแค่ไหน

## โหมดการทำงาน 3 แบบ

### 1. `paper` — จำลอง (เริ่มต้น)
ไม่ต่อโบรกเกอร์ ใช้ราคาจริงจาก Yahoo แต่ไม่ส่งออร์เดอร์ **เหมาะกับการทดสอบ**

### 2. `ea` — ให้ MetaTrader 5 เป็นคนเปิดออร์เดอร์

ตั้ง `XAU_BROKER=ea` แล้วติดตั้ง EA:

1. คัดลอก `trading_webapp/mt5_ea/XAUUSD_Bridge_EA.mq5` ไปที่โฟลเดอร์ `MQL5/Experts/` ของ MT5
2. เปิด MetaEditor กด **Compile**
3. ใน MT5 ไปที่ **Tools → Options → Expert Advisors**
   ติ๊ก **Allow WebRequest for listed URL** แล้วเพิ่ม `http://127.0.0.1:8000`
4. ลาก EA ลงกราฟ XAUUSD ตั้งค่า `InpApiToken` ให้ตรงกับรหัสใน `.env`
5. **ปล่อย `InpDryRun = true` ไว้ก่อน** — EA จะแค่บันทึก log ไม่เปิดออร์เดอร์จริง
6. ดู log ใน tab **Experts** ว่าได้รับสัญญาณถูกต้อง แล้วค่อยเปลี่ยนเป็น `false`

### 3. `metaapi` — ส่งออร์เดอร์ผ่านคลาวด์
ตั้ง `XAU_BROKER=metaapi` พร้อมใส่ `XAU_METAAPI_TOKEN` และ `XAU_METAAPI_ACCOUNT_ID`
ข้อดีคือไม่ต้องเปิดคอมทิ้งไว้ แต่ต้องสมัครบริการ MetaApi

> **ทั้งโหมด `ea` และ `metaapi` จะยังไม่ส่งออร์เดอร์จริง** จนกว่าจะตั้ง `XAU_ALLOW_LIVE=true`

## ต่อกับ Langflow

1. เปิด Langflow → **Import** → เลือกไฟล์ `xauusd_preset_advisor_flow.json`
2. คลิกโหนด **LLM** ใส่ API key ของคุณ
3. คลิกโหนด **Publish To Bridge** แก้ 2 บรรทัดบนสุด:
   ```python
   BRIDGE_URL = "http://127.0.0.1:8000"
   API_TOKEN  = "รหัสที่คุณตั้งไว้"
   ```
4. กด Run แล้วพิมพ์สภาพตลาดปัจจุบันลงไป

โฟลว์จะให้ AI ตอบเป็น JSON แล้วส่งต่อเข้าเซิร์ฟเวอร์ให้อัตโนมัติ
ถ้า AI ตอบ `HOLD` จะไม่ส่งอะไรเลย

## หาค่าพารามิเตอร์ที่ดีที่สุด

```bash
cd grid_optimizer
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# ใช้ข้อมูลจริงจากไฟล์ CSV (แนะนำ — ทำซ้ำได้)
python optimize.py --csv data/XAUUSD_H1.csv --trials 300

# หรือดึงข้อมูลจาก Yahoo
python optimize.py --source yahoo --trials 200
```

ผลจะถูกบันทึกลง `best_params.json` พร้อมแยกผล **train** กับ **test** ให้เห็นชัด

จากนั้นให้ตัวตรวจสอบดูว่าผลน่าเชื่อถือไหม:

```bash
cd ../eval_agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python evaluate.py ../grid_optimizer/best_params.json
```

ตัวตรวจจะให้คำตัดสิน 3 ระดับ:

- **APPROVED** — ผ่าน ลองเอาไปทดสอบบนเดโมได้
- **CAUTION** — ใช้ได้แต่ต้องเข้าใจข้อควรระวัง
- **REJECTED** — อย่าเอาไปเทรด

มันจะจับได้ทั้งกรณีจำนวนเทรดน้อยเกินไป, drawdown สูงเกิน, และที่สำคัญที่สุดคือ **overfitting** (ผลดีเฉพาะข้อมูลเก่า พอเจอข้อมูลใหม่แล้วเจ๊ง)

ถ้าอยากให้ AI อธิบายเป็นภาษาไทยเพิ่ม:

```bash
export ANTHROPIC_API_KEY=...
python evaluate.py ../grid_optimizer/best_params.json --llm --lang th
```

## ข้อควรรู้ก่อนใช้เงินจริง

1. **`XAU_API_TOKEN` คือกุญแจสั่งเทรด** ใครได้ไปสั่งเปิดออร์เดอร์ในพอร์ตคุณได้ อย่าเปิดพอร์ต 8000 ออกอินเทอร์เน็ตตรงๆ ถ้าจะเข้าจากข้างนอกให้ผ่าน VPN หรือ reverse proxy ที่มี HTTPS
2. **โหมด `ea` บันทึกแค่ "เจตนา"** ระบบจดว่าสั่งอะไรไป แต่ความจริงว่าออร์เดอร์เข้าหรือไม่ ราคาเท่าไหร่ ต้องดูที่ MetaTrader เป็นหลัก ควรเทียบยอดกับ MT5 เสมอ
3. **ราคาจาก Yahoo เป็นราคาทองล่วงหน้า (GC=F)** ไม่ใช่ราคาจากโบรกเกอร์คุณเป๊ะๆ ใช้ประเมินคร่าวๆ ได้ แต่โหมดเงินจริงควรใช้ราคาจากโบรกเกอร์
4. **เพดานขาดทุนต่อวันเป็นตาข่ายกันตาย ไม่ใช่กลยุทธ์** ถ้าชนบ่อย แปลว่าระบบมีปัญหา ไม่ใช่แค่โชคร้าย
5. **ผลทดสอบย้อนหลังไม่ได้รับประกันอนาคต** โดยเฉพาะเมื่อได้มาจากการ optimize — นั่นคือเหตุผลที่ต้องมี `eval_agent`

## ถ้าเจอปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| แดชบอร์ดขึ้น "รหัส API ไม่ถูกต้อง" | รหัสในเบราว์เซอร์ไม่ตรงกับ `XAU_API_TOKEN` ใน `.env` — ต้องรีสตาร์ทเซิร์ฟเวอร์หลังแก้ `.env` |
| EA ขึ้น `ERROR 4060` ใน log | ยังไม่ได้เพิ่ม URL ใน MT5 → **Tools → Options → Expert Advisors → Allow WebRequest** |
| ราคาขึ้น "ราคาไม่พร้อม" | ต่อ Yahoo ไม่ได้ (เน็ตหรือไฟร์วอลล์) ลองตั้ง `XAU_PRICE_FEED=static` เพื่อทดสอบส่วนอื่นก่อน |
| สัญญาณถูกปฏิเสธตลอด | ดูคอลัมน์ "เหตุผล" ในตารางสัญญาณบนแดชบอร์ด — บอกชัดว่าติดด่านไหน |
| `computed volume below the broker minimum` | พอร์ตเล็กเกินไปเมื่อเทียบกับระยะ SL — ลด SL ให้แคบลง หรือเพิ่ม `XAU_RISK_PERCENT` |
| `port already in use` | มีเซิร์ฟเวอร์เดิมค้างอยู่ — ปิดด้วย `pkill -f uvicorn` หรือเปลี่ยนพอร์ต |
