# ภาพพื้นหลังเคลื่อนไหว (AUTO 1 Living Background)

ภาพในโฟลเดอร์นี้ถูกเรียกจาก `quotation.html` (ค่าตั้งต้นอยู่ที่ `LB_SCENES` ในสคริปต์) โดยโหลดตอนใกล้จะแสดง ไม่มีไฟล์วิดีโอ

| ฉาก | ไฟล์ (คอม / มือถือ) | ภาพ |
|---|---|---|
| `workshop` โรงซ่อม AUTO 1 | `auto1-workshop.webp` (1536×1024) / `auto1-workshop-sm.webp` (960×640) | ช่างตรวจเครื่องยนต์ แท็บเล็ตวิเคราะห์ ลิฟต์ยกรถ ป้าย AUTO1 และโฮโลแกรมรถ |

- โลโก้ "AUTO1 ใบเสนอราคารถยนต์" และข้อความ "รถทุกคันมีคุณค่า เราดูแลให้" ถูกลบออกจากภาพต้นฉบับแล้ว เพราะเว็บมีโลโก้และหัวข้อของตัวเอง
- ภาพมีฉากเดียว จึงไม่มีการเฟดสลับฉาก ภาพจะซูมและเลื่อนช้า ๆ ไปมาเอง พร้อมแสงวิบวับที่แท็บเล็ต ไฟหน้ารถ ไฟเพดาน ป้าย AUTO1 และโฮโลแกรม เส้นสแกนวิ่งผ่านห้องเครื่อง และฝุ่นละอองลอย
- ภาพ `-sm` ใช้กับหน้าจอกว้างไม่เกิน 700px และผู้ใช้ที่เปิดโหมดประหยัดข้อมูล
- ถ้าภาพโหลดไม่ได้ เว็บทำงานต่อได้ตามปกติ (เห็นพื้นสีน้ำเงินเข้มกับเส้นวงจร)
- ภาพชุดเดิม (ตรวจเครื่อง / ถอดล้อ ×2 / ทีมช่างอนิเมะ) ยังอยู่ในประวัติ git ก่อนคอมมิตที่ใส่ภาพนี้ ถ้าอยากกลับไปใช้

## เปลี่ยนภาพ

1. ครอปภาพให้ไม่มีข้อความหรือแถบดำติดมา บันทึกเป็น WebP ชื่อ `auto1-<id>.webp` (กว้างไม่เกิน ~1500px, quality ประมาณ 75) และทำสำเนาสูง 640px ชื่อ `auto1-<id>-sm.webp`
2. ใน `LB_SCENES` ของ `quotation.html` แก้ `id`, `ar` (กว้าง ÷ สูงของภาพ) และ `fx`/`fy` (จุดที่อยากให้อยู่กลางจอ เป็นสัดส่วน 0–1)
3. จุดแสง (`glows`) และเส้นสแกน (`scan`) ระบุเป็นสัดส่วนของภาพเอง จึงตรงกับภาพเสมอไม่ว่าหน้าจอขนาดไหน ถ้าใส่ `spark:{x,y}` จะมีประกายไฟที่ตำแหน่งนั้น (เหมาะกับภาพถอดล้อ)
4. ถ้าใส่หลายฉาก (`special:true` = ฉากพิเศษขึ้นทุกสองรอบ) ระบบจะเฟดสลับฉากเอง และหน้าตั้งค่าจะแสดงตัวเลื่อนเวลาต่อฉากกลับมา

## ปรับการเคลื่อนไหว

- ที่หน้า ตั้งค่าระบบ → พื้นหลังเคลื่อนไหว: ความแรงของการเคลื่อนไหว (0 = นิ่ง), ความสว่างภาพ, เปิด/ปิด
- หรือแก้ค่าตั้งต้นที่ `LB_DEFAULTS` หรือสั่งจากคอนโซล เช่น `AUTO1_BG.set({ motion: 1.5, bright: 1.2 })`
