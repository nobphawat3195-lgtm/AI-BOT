# ภาพพื้นหลังเคลื่อนไหว (AUTO 1 Living Background)

ภาพทั้งหมดในโฟลเดอร์นี้ถูกเรียกจาก `quotation.html` (ค่าตั้งต้นอยู่ที่ `LB_SCENES` ในสคริปต์) โดยโหลดทีละภาพตอนใกล้จะแสดง ไม่มีไฟล์วิดีโอ

| ฉาก | ไฟล์ (คอม / มือถือ) | ครอปจากภาพต้นฉบับ | ใช้ทำอะไร |
|---|---|---|---|
| `repair` ตรวจเช็กเครื่องยนต์ | `auto1-repair.webp` / `-sm.webp` | ภาพช่างตรวจเครื่อง ตัดโลโก้และข้อความด้านซ้ายบนออก | แสงที่แท็บเล็ตวิเคราะห์ ไฟหน้ารถ ป้าย AUTO1 ไอคอนโฮโลแกรม และเส้นสแกนวิ่งผ่านห้องเครื่อง |
| `wheel-dark` ถอดล้อ | `auto1-wheel-dark.webp` / `-sm.webp` | ภาพถอดล้อโทนมืด ตัดแถบดำบน-ล่างออก | ไฟนีออนสีน้ำเงิน แสงสะท้อนบนล้อ และประกายไฟที่ปลายประแจ |
| `wheel-bay` ถอดล้อในอู่ | `auto1-wheel-bay.webp` / `-sm.webp` | ภาพช่างคุกเข่าถอดล้อ ตัดโลโก้และกล่องข้อความด้านซ้ายออก | ไฟเพดาน แถบสีน้ำเงิน และประกายไฟที่ปลายประแจ |
| `team` ทีมช่างอนิเมะ | `auto1-team.webp` / `-sm.webp` | ภาพทีมช่าง ตัดแถบดำด้านล่างออก | ลำแสงจากหน้าต่าง เป็นฉากพิเศษ ขึ้นทุกสองรอบและสั้นกว่าฉากอื่น 30% |

- ภาพถูกปรับโทนให้เข้ากับธีมน้ำเงินเข้มไว้ล่วงหน้า (ภาพทีมช่างลดความสดลงและเพิ่มโทนน้ำเงิน) ความมืดของภาพขณะใช้งานปรับได้ที่ ตั้งค่าระบบ → พื้นหลังเคลื่อนไหว
- ภาพ `-sm` ใช้กับหน้าจอกว้างไม่เกิน 700px และผู้ใช้ที่เปิดโหมดประหยัดข้อมูล
- ถ้าภาพใดโหลดไม่ได้ ฉากนั้นจะถูกข้ามไปเอง และเว็บทำงานต่อได้ตามปกติ

## เปลี่ยนภาพ

1. ครอปภาพให้ไม่มีข้อความหรือแถบดำติดมา บันทึกเป็น WebP ชื่อ `auto1-<id>.webp` (กว้างไม่เกิน ~1300px, quality ประมาณ 75) และทำสำเนาสูง 640px ชื่อ `auto1-<id>-sm.webp`
2. ใน `LB_SCENES` ของ `quotation.html` แก้ `ar` (กว้าง ÷ สูงของภาพ) และ `fx`/`fy` (จุดที่อยากให้อยู่กลางจอ เป็นสัดส่วน 0–1)
3. จุดแสงและประกายไฟ (`glows`, `spark`) ระบุเป็นสัดส่วนของภาพเอง จึงตรงกับภาพเสมอไม่ว่าหน้าจอขนาดไหน

## ปรับความเร็ว / ช่วงเวลา

- ที่หน้า ตั้งค่าระบบ: เวลาต่อฉาก, ความนุ่มนวลตอนเปลี่ยนฉาก, ความแรงของการเคลื่อนไหว (0 = นิ่ง), ความสว่างภาพ, เปิด/ปิด
- หรือแก้ค่าตั้งต้นที่ `LB_DEFAULTS` หรือสั่งจากคอนโซล เช่น `AUTO1_BG.set({ sceneSeconds: 12, fadeSeconds: 3 })`
