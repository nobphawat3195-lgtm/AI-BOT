ขั้นตอน — รับ & ติดตั้งเวอร์ชันฟรี
1

แอด LINE OA ของร้าน แล้วพิมพ์ว่า "ขอโค้ดฟรี"

กดปุ่ม LINE ด้านล่าง หรือค้นหา @YOUNGYUU ใน LINE แอดเป็นเพื่อนแล้วส่งข้อความมา — เราจะส่งโค้ด Pine Script กลับไปให้ทันที

✅
ไม่ต้องสมัครสมาชิก · ไม่เสียเงิน · รับได้ทันที
2

เปิด TradingView แล้วไปที่กราฟ

เข้า tradingview.com (บัญชีฟรีก็ใช้ได้) → กดที่กราฟของสินทรัพย์ที่ต้องการ เช่น XAUUSD, BTC, SET50

📱 เปิดแอป TradingView หรือเว็บล็อกอิน → เลือกชาร์ต → กดกราฟ
3

เปิด Pine Editor

บนกราฟ ให้มองหาแถบเมนูด้านล่าง กด "Pine Editor" (หน้าต่างเขียนโค้ดจะเปิดขึ้นมาด้านล่าง)

💡
ถ้าไม่เห็น Pine Editor → กด "< >" (ไอคอนโค้ด) ที่แถบเมนูล่างของกราฟ หรือ กด Alt+P
🖥️ แถบล่างกราฟ → Pine Editorมองหาแท็บ "Pine Editor" ที่แถบล่าง
4

ลบโค้ดเดิม แล้ววางโค้ด YOUNGYUU

ใน Pine Editor จะมีโค้ดตัวอย่างอยู่แล้ว ให้ทำ 3 อย่าง:

วิธีลบโค้ดเดิม
กด Ctrl+A (Windows) หรือ Cmd+A (Mac) เพื่อเลือกทั้งหมด → กด Delete หรือ Backspace
วิธีวางโค้ดใหม่
คัดลอกโค้ด YOUNGYUU ที่ได้รับจาก LINE แล้ว Ctrl+V (Windows) หรือ Cmd+V (Mac)
⚠️
ต้องลบโค้ดเดิมออกทั้งหมดก่อนวาง — ถ้าวางทับโดยไม่ลบจะเกิด Error
5

กด "Add to chart" เพื่อโหลดลงกราฟ

หลังวางโค้ดแล้ว กดปุ่ม "Add to chart" สีน้ำเงิน (หรือ Ctrl+Enter) ที่มุมบนขวาของ Pine Editor — รอสักครู่ อินดิเคเตอร์จะโหลดลงกราฟ

🎉
เห็นสัญญาณ ▲ BUY (เขียว) และ ▼ SELL (แดง) บนกราฟ = ติดตั้งสำเร็จ!
6

บันทึก Script ของคุณ

กด Ctrl+S (หรือปุ่ม Save ในเมนู) เพื่อบันทึกโค้ดไว้ใน My Scripts ของคุณ — ครั้งต่อไปหาใน "Indicators → My Scripts" ได้เลยโดยไม่ต้องวางโค้ดใหม่

ตั้งชื่อ Script แนะนำ
YOUNGYUU Lite (Free)

ปรับ Timeframe และทดสอบ

ลองเปลี่ยน Timeframe บนกราฟ (เช่น 5m / 15m / 1H / 4H) — สัญญาณจะปรับตัวตาม Timeframe ที่เลือกอัตโนมัติ

💡
แนะนำสำหรับทอง (XAUUSD): เริ่มที่ 15m หรือ 1H
แนะนำสำหรับ Crypto: เริ่มที่ 1H หรือ 4H
Scalp: 5m หรือ 1m (สัญญาณมากกว่า แต่ต้องระวังมากกว่า)

รับโค้ดทาง LINE หลังชำระเงิน

หลังโอนเงินและส่งสลิปแล้ว เราจะส่งโค้ด Pine Script + คู่มือการตั้งค่ากลับทาง LINE ภายใน 24 ชม. (ปกติไม่เกิน 1 ชม.)

📦
โค้ดจะถูก watermark ด้วยชื่อ TradingView + อีเมลของคุณ — ห้ามแชร์หรือขายต่อ
2

ทำตามขั้นตอน 3–7 ข้างบน

กระบวนการเดียวกันทุกอย่าง — เปิด Pine Editor → ลบโค้ดเดิม → วางโค้ดใหม่ → Add to chart → Save

🔓
เวอร์ชันเต็มจะเห็น TP1/TP2/TP3, Stop Loss, Dashboard และ Alert เพิ่มขึ้นทันที
3

ตั้ง Alert บนมือถือ (เฉพาะเวอร์ชันเต็ม)

Q: ต้องสมัครบัญชี TradingView ระดับไหน?

A: บัญชีฟรี (Basic) ก็ใช้ได้ — วาง Pine Script แล้วกด Add to chart ได้เลย ข้อจำกัดเดียวคือจำนวน indicator ต่อกราฟ (ฟรี ~2-3 ตัว) และ Alert (ฟรี 1 รายการ)

Q: ติดตั้งแล้วต้องทำซ้ำทุกครั้งไหม?

A: ไม่ — กด Save ครั้งเดียว แล้วหาได้ใน "Indicators → My Scripts" ตลอด หรือบันทึกเป็น Template กราฟก็ได้

Q: สัญญาณรีเพนต์ไหม?

A: ไม่ — ทุกตัวใช้ barstate.isconfirmed ยืนยันเมื่อแท่งเทียนปิดเท่านั้น สัญญาณที่ปรากฏจะไม่หายไปหรือเปลี่ยน

Q: อินดิเคเตอร์การันตีกำไรไหม?

A: ไม่ — เป็นเครื่องมือวิเคราะห์ ไม่ใช่คำแนะนำลงทุน การเทรดมีความเสี่ยง ต้องใช้ร่วมกับการบริหารความเสี่ยง (Risk Management) ของตัวเองเสมอ
